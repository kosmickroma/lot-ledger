## Phase 0 — Reframe

### The data discovery (most important moment of the session)

KK said: *"Our current ingest of the redfin stuff is not right... and also
this way in the subject folder we are looking at is legal because it uses
the clients login."*

Two things fell into place:

1. **Redfin's `sold_price` field is an estimate**, not an MLS-actual close
   price. Texas is a non-disclosure state — counties don't publish sold
   prices. Redfin can show list prices, days on market, and their own AVM,
   but the actual closed sale price isn't in public records. Mike's been
   making decisions on Redfin estimates dressed up as sold prices.
2. **Mike has a paid Propelio subscription with broker-licensed MLS data.**
   "Propelio Realty LLC" is a brokerage with NTREIS access. Pulling Mike's
   own data through Mike's own login is just authorized customer usage,
   not third-party scraping. The legal posture of my original brief was
   wrong — it assumed multi-tenant SaaS distribution.

Implication: my original "lift the algorithm" framing was inverted. The
algorithm *is* nice but Mike is a flipper/teardown buyer; the algorithm's
living-area filter (±40%) excludes exactly the comps he most needs (a
1,413 sqft teardown's relevant comp is the 4,000 sqft new build that
replaced something similar nearby). KK confirmed Mike wants raw data, all
comps the same color, and he'll pick manually.

**Net change:** drop the algorithm (`comp_engine.py`, `output.py`), keep
the scraper.

### Local boot pain (multiple fixes)

Booting uvicorn locally hit a chain of issues:

1. **PEP 668 "externally-managed-environment"** — the `pip install`
   command was finding system Python instead of the venv. Fix: clean
   activate with `source .venv/bin/activate` then verify with `which uvicorn`.
2. **Wrong uvicorn picked up** — system uvicorn (Python 3.12) was getting
   chosen even with venv prompt visible. Workaround: call venv's uvicorn
   by full path: `.venv/bin/uvicorn api.main:app --reload --host 0.0.0.0 --port 8000`.
3. **Missing `SESSION_SECRET`** in `.env` — required by `api/auth.py:60`.
   Generated random with `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
4. **Missing `AUTH_COOKIE_SECURE=false`** — auth cookies require https unless
   set false; needed for `http://localhost`.
5. **Missing `BOOTSTRAP_DEV_EMAIL` / `BOOTSTRAP_DEV_PASSWORD`** —
   `seed_bootstrap_users()` validates these env vars exist *before*
   short-circuiting on existing-user count. Set placeholder values
   (`dev@local.test` / `local-dev-only-not-real`) since the seed function
   bails on existing users in the shared Cloud SQL.

### Frontend — empty-result UX

When Propelio resolves an address but its CMA returns zero comps
(low-velocity neighborhood under the default narrow filter), the route
catches the `PropelioScraperError` containing "empty list" and returns
**200 with `comps: []` + a `warning` field** instead of 503. The CMA chip
detects 0 comps and shows:

```
PROPELIO CMA — 0 COMPS
Propelio resolved this address but returned 0 comps under their default filter
(typically 0.5mi · 6mo · similar lot size). Try a higher-activity neighborhood,
or wait for the filter-widen feature.
Try: 4044 Williamsburg Rd · 6710 Northport Dr · 9012 Hunters Creek Dr
```

This was discovered while testing `5528 Victor St, Dallas, TX` — Propelio
resolved the address (lead created) but the CMA was empty under their
default filter (likely few similar-lot recent sales nearby).

### Filter-widening attempt (failed)

Tried to widen Propelio's CMA filters via custom params:

| Variant | Result |
|---|---|
| `GET /legacy/cma/{lead_id}?months=24&range=2.0` | 400 — "Invalid longitude argument" |
| `GET /legacy/cma/{lead_id}?lat=&lon=&months=24&range=2.0` | 400 same error |
| `POST /legacy/cma/{lead_id}` with full mirrored params + lat/lon | 500 — generic api_error |
| `PATCH/PUT/POST /legacy/cma/{cma_internal_id}` (using the CMA's own id, not lead_id) | HTML error page (wrong path) |
| `POST /legacy/cma` with lead_id in body | HTML page (not the API) |

Conclusion: widening requires watching Propelio's web app's network calls
to mirror the exact request shape. Deferred to roadmap.
